# Como contribuir

O Scriptorium é um espaço de estudo em público. Sugestões de temas, referências, correções e casos públicos são bem-vindos.

## Formas de contribuir

| Quero... | Como |
|---|---|
| Sugerir um tema ou referência | Abra uma issue com o título, o link e por que vale a pena |
| Indicar um caso público | Abra uma issue com o link da fonte original |
| Corrigir um erro, link ou fonte | Abra uma pull request direto no arquivo |
| Escrever um documento novo | Abra uma issue antes, para combinarmos o código e o tipo |

## Princípios

- Prefira fontes originais e links verificáveis.
- Deixe claro quando algo é opinião, experiência pessoal ou resultado publicado.
- Não apresente uma prática como solução universal sem considerar o contexto.
- Respeite autoria e licenças: resuma com suas palavras e cite.
- Nada de material de trabalho, de cliente ou confidencial.

## Padrão

Nomes, metadados, imagens e o que pode entrar estão em [`PADRAO.md`](PADRAO.md). Os modelos de documento ficam em [`90-modelos/`](90-modelos/).

Commits em inglês, no formato [Conventional Commits](https://www.conventionalcommits.org/):

```
docs: add CAS-002 on GitHub Docs
fix: correct broken link in NOT-003
```
