# Documentação na prática

Exemplos e modelos que podem ser adaptados a projetos reais.

## Ideias de conteúdo

- README de projeto
- Guia de instalação e execução
- Guia de contribuição
- Referência de API
- Registro de decisões arquiteturais (ADR)
- Guia de troubleshooting
- Checklist para revisar documentação

A ideia não é criar uma regra universal para todos os projetos, mas mostrar opções e explicar quando cada uma pode ser útil.
