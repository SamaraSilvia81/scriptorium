# Engenharia de software

Assuntos relacionados à documentação que podem ajudar a entender decisões e problemas do desenvolvimento de software.

## Temas possíveis

- Arquitetura de software
- Manutenibilidade e evolução de sistemas
- Dívida técnica
- Microfrontends
- Design de APIs
- Comunicação e compartilhamento de conhecimento em equipes

Este diretório amplia a conversa sem tirar a documentação técnica do centro do projeto. Os assuntos entram quando ajudarem a explicar um problema, uma decisão ou uma prática.
