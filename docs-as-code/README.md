# Docs-as-code

Práticas que aproximam a documentação do fluxo de desenvolvimento de software.

## Temas possíveis

- Documentação versionada junto ao código
- Pull requests e revisão de documentação
- Markdown e formatos legíveis por pessoas e ferramentas
- Geração e publicação automatizada
- Documentação como parte do fluxo de entrega

## Para cada ferramenta ou abordagem

Registre o problema que ela resolve, como funciona, em que contexto faz sentido e quais são suas limitações. Evite recomendar ferramentas sem explicar o cenário de uso.
